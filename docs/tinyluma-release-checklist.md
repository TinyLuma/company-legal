## 发布核对（不进入用户正文）

1. 确认公司、邮箱、日期、政策正式URL；文档入口无需购买。
2. 月度／年度属于同一订阅组，两者配置3天试用；实际资格由Apple判定。客户端不以安装次数自行判断。
3. 后台及App Store配置3天宽限期、适用已付费续费；本稿不能替代实际配置。
4. 购买完成／恢复后同步权限；允许页正常使用，不把未付费、到期、恢复为空作为全App阻断条件。
5. 首页／历史底栏可切换；检查和恢复采用临时浮层，原页面不改动；亲喂正常结束保存。组件不受订阅限制。
6. 不设计应用内续费付款提醒。邮件通知另行落实；本稿不承诺每次发送或送达，也不新增邮箱采集。
7. 月度与年度放在同一组同一级；切换计费周期交给Apple。设置仅保留订阅管理入口，恢复链接放在订阅遮罩。
8. 发布前核对服务承诺及美国适用法律；法律文本不能用来隐藏购买前明确承诺的功能。
